# Словарь данных

## `data/raw/users.csv` – одна строка на пользователя

| Поле | Значение |
|---|---|
| `user_id` | Анонимный синтетический идентификатор пользователя, уникален |
| `registered_at` | Момент регистрации, UTC (`YYYY-MM-DD HH:MM:SS`) |
| `platform` | `android` или `ios` |
| `channel` | Канал привлечения: `organic`, `ads`, `referral`, `social` |

## `data/raw/events.csv` – одна строка на действие

| Поле | Значение |
|---|---|
| `event_id` | Уникальный идентификатор события |
| `user_id` | Указывает на пользователя из `users.csv` |
| `event_name` | Тип действия |
| `event_time` | Время действия, UTC |

## Какие бывают события

1. **`signup`** – зарегистрировался.
2. **`address_added`** – указал адрес доставки.
3. **`restaurant_opened`** – открыл страницу ресторана.
4. **`added_to_cart`** – положил товар в корзину.
5. **`checkout_started`** – начал оформление заказа.
6. **`payment_failed`** – получил ошибку оплаты; дополнительное событие, **не обязательный шаг** воронки.
7. **`order_completed`** – завершил первый заказ.
8. **`repeat_order_completed`** – совершил повторную покупку после первой.

## Гранулярность

- `users` – **один пользователь на строку**.
- `events` – **одно событие на строку**, одному пользователю соответствует несколько событий.
- `user_funnel` – после SQL-преобразования **один пользователь на строку**; `NULL` на шаге значит, что не дошёл до него в допустимом окне.
- Список допустимых событий и их последовательность открыты в генераторе и проверяются в анализе.

Данные иллюстративные. Нет реального адреса, номера карты, фамилии, контактов и иных персональных данных.
